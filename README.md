# PharmaLog – Motion Poster (9:16)

โปสเตอร์ดิจิทัลแนวตั้งสำหรับจอ 1080×1920 วนเล่น 4 หน้าอัตโนมัติ (ประมาณ 44 วินาทีต่อรอบ)
เป็นไฟล์ static ล้วน (HTML/CSS/JS) ไม่ต้อง build พร้อมขึ้น Vercel

## โครงสร้าง

```text
index.html        เนื้อหาทั้ง 4 หน้า
css/style.css     ดีไซน์และแอนิเมชันทั้งหมด
js/app.js         ตัวคุมไทม์ไลน์, ทรานสิชันแคปซูล, ปรับขนาดให้พอดีจอ
assets/favicon.svg
vercel.json
```

## หน้าในโปสเตอร์

| # | หน้า | เวลา |
|---|------|------|
| 1 | PharmaLog คืออะไร: แคปซูลตกลงมาแล้วแยกออก เสียงพูดกลายเป็นบันทึก | 10 วิ |
| 2 | ทำงานอย่างไร? 3 ขั้นตอน + หมวดข้อมูล EMR | 12.5 วิ |
| 3 | ดูแลใส่ใจ ข้อมูลถูกต้อง แม่นยำ (ความปลอดภัย) | 12 วิ |
| 4 | ปิดท้าย: โลโก้ + เครดิตมหาวิทยาลัย | 9 วิ |

ฟอนต์ Anuphan (Google Fonts, สำรองด้วย Sukhumvit Set บน Mac) โทนสีฟ้า แก้สีหลักได้ที่ `:root` ใน `css/style.css`

เปลี่ยนเวลาแต่ละหน้าได้ที่ `data-dur` ของแต่ละ `<section class="scene">` ใน `index.html`
และจังหวะที่แต่ละชิ้นโผล่ที่ `data-at` (มิลลิวินาทีนับจากต้นหน้า)

## ใช้งาน

- เปิด `index.html` ในเบราว์เซอร์ได้เลย
- ขยับเมาส์ / แตะจอ เพื่อเรียกปุ่มควบคุม (หายเองหลัง 2.5 วิ พร้อมซ่อนเคอร์เซอร์)
- คีย์ลัด: `F` เต็มจอ · `Space` หยุด/เล่น · `←` `→` เปลี่ยนหน้า
- พารามิเตอร์ URL:
  - `?scene=2` เริ่มที่หน้า 2
  - `?pause=1` เริ่มแบบหยุด
  - `?speed=0.8` ปรับความเร็ว
  - `?controls=0` ไม่ต้องแสดงปุ่มเลย (เหมาะกับจอ signage)

## Deploy ขึ้น Vercel

```bash
npm i -g vercel
cd pharmatalk_motion_poster
vercel --prod
```

หรือ push ขึ้น GitHub แล้ว Import ใน vercel.com — Framework Preset เลือก **Other**, ไม่ต้องตั้ง Build Command
